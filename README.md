#Arteria App Interface for the Congressional App Challenge

A practical & accessible interface designed for any user. 
Key accessibility features include:
1. Language Accessibility (the app is available in both English & Spanish)
2. High Contrast
3. Limit Motion
4. Keyboard Friendly

Primary features:
1. AI companion - Aria
2. Photon
3. Find a nearby clinic
4. Care plan & encrypted data sharing
5. Trends
6. Medical Info
